# UtaBendr

A (more) accurate notebend-based utau to vocaloid sequence file converter.

## Usage

### Windows executable

Drag a `.ust` or `.vsqx` file onto `UtaBendr.exe`.

You can also double-click the executable and choose a file manually.


Default output names:

```text
song.ust  → song_notebend.vsqx
song.vsqx → song_converted.ust
```
